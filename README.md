# 📚 Redes de Computadoras - Material de Estudio para Parcial (UMG)

Repositorio de estudio teórico y práctico para el examen de Redes de Computadoras en la Universidad Mariano Gálvez de Guatemala.

---

## 📑 Índice de Contenidos

### Módulo 1: Capa de Transporte (Capa 4 OSI)
* 📘 [1.1 Fundamentos de la Capa de Transporte](Teoria/Modulo_1_Capa_Transporte/01_Fundamentos_Capa_Transporte.md)
  * Entrega Process-to-Process vs Host-to-Host.
  * Concepto de Socket y Socket Pair.
  * Clasificación de puertos IANA (Bien conocidos, Registrados, Dinámicos/Efímeros).
* 📘 [1.2 Protocolo TCP (RFC 793)](Teoria/Modulo_1_Capa_Transporte/02_Protocolo_TCP.md)
  * Características y anatomía del encabezado (20 a 60 bytes).
  * Three-Way Handshake (SYN, SYN-ACK, ACK) y Four-Way Teardown.
  * Confiabilidad (Seq / Ack) y Ventana Deslizante (Window Size).
* 📘 [1.3 Protocolo UDP (RFC 768)](Teoria/Modulo_1_Capa_Transporte/03_Protocolo_UDP.md)
  * Características y encabezado fijo de 8 bytes.
  * Justificación de velocidad sobre confiabilidad.
  * Protocolos dependientes de UDP (DNS, DHCP, TFTP, VoIP).
* 📘 [1.4 Comparativa TCP vs. UDP y Banco de Preguntas](Teoria/Modulo_1_Capa_Transporte/04_Comparativa_TCP_vs_UDP.md)
  * Gran matriz comparativa para examen.
  * Mapeo de protocolos de Capa 7 a Capa 4.
  * Preguntas de selección múltiple tipo examen UMG resueltas.

## 📱 Cómo leer este material en tu celular Android sin conexión

1. **Opción A (Recomendada - Con la App de GitHub):**
   * Descarga la app oficial de **GitHub** desde la Play Store.
   * Entra a tu repositorio: `https://github.com/ch4rf/redes-computadoras`.
   * En la pestaña "Code", puedes ver los archivos `.md` perfectamente formateados con tablas, listas y código.
2. **Opción B (100% Offline con lectores Markdown locales):**
   * Descarga los archivos `.md` a tu teléfono o descárgalos como `.zip` desde GitHub.
   * Instala en Android lectores ligeros de Markdown como:
     * **Obsidian** (excelente soporte offline, navegación entre notas y tablas).
     * **Markor** (lector/editor markdown gratuito, de código abierto, ligero y sin publicidad).
     * **GitJournal** (sincroniza directamente con repositorios de GitHub offline).
